# Git Commands to Push SQLite Branch

## 1. Add all files
git add .

## 2. Commit changes
git commit -m "Add SQLite support - simplified database setup

- Replace PostgreSQL with SQLite for easier setup
- Add aiosqlite driver
- Update SQL queries for SQLite compatibility
- Add Windows setup scripts (setup.bat, start.bat)
- Add init_db.py for database initialization
- Update docker-compose.yml (remove PostgreSQL service)
- Keep all GridStack drag & drop functionality
- All widgets working perfectly

Benefits:
- No separate database server needed
- Single file database (dashboard.db)
- Native Windows support
- Faster development setup
- Easy backup and restore"

## 3. Create SQLite branch (if not exists)
git branch sqlite

## 4. Switch to SQLite branch
git checkout sqlite

## 5. Add remote (replace with your GitHub repo)
git remote add origin https://github.com/pratikgr/configurable-dashboard-system.git

## 6. Push to SQLite branch
git push -u origin sqlite

## Alternative: Force push (if branch exists and you want to overwrite)
git push -f origin sqlite

## To switch back to main
git checkout main

## To merge SQLite into main (if desired)
git checkout main
git merge sqlite

## View changes
git status
git diff

## View commit history
git log --oneline
